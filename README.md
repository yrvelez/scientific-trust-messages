# Can Trust in Science Be Improved? An Adaptive Experiment Testing Student-Designed Messages

Study package from [The File Drawer](https://filedrawer.org), built with the
[filedrawer](https://github.com/yrvelez/filedrawer) pipeline. An adaptive survey experiment on Lucid (November-December
2021) testing 32 brief messages, designed by students in an undergraduate experiments course, against a pure control
on a 6-item trust-in-science scale. Findings are in [`report.md`](report.md).

- Pre-registered on OSF: https://osf.io/5yvh9 (DOI 10.17605/OSF.IO/5YVH9, 2021-11-20), amended by
  https://osf.io/w82xv (assignment algorithm) and https://osf.io/5wr2k (Lin covariate adjustment). `inputs/pap.md`
  transcribes the plan; `inputs/pap.json` is its structured form.
- De-identified respondent-level data are included: `data/raw_tidy.csv` (all pooled responses) and `data/clean.csv`
  (the analysed sample). `codebook.md` describes every column. Lucid ids, ZIP codes, IP addresses and locations, the
  free-text answers and the message texts were removed before any model saw the data.
- `prepare_pipeline_input.py` pools the seven fielding batches from the raw Qualtrics exports (not included: they
  hold identifiers) and builds the trust scales, covariates and assignment weights.
- The report was generated by the pipeline with no human review recorded (see the provenance badge).
- Carried out in collaboration with Julian Gerez (see `ACKNOWLEDGMENTS.md`).

## Reproduce

```bash
pip install pandas numpy statsmodels scipy matplotlib
python scripts/02_clean.py        # data/raw_tidy.csv -> data/clean.csv
python scripts/03_registered.py   # registered analyses -> results/
python scripts/04_exploratory.py  # exploratory analyses
```

Or, with the tool installed: `filedrawer reproduce .` re-runs the scripts and checks every table in `results/`.
